今回は、sample・ヒントに頼らずに、7-3-2,3を参考に羅列してから、分からないところをヒントを見て書き写し、デバイスで反映したものを確認しながら、自力で羅列調整しました。
どうしても分からなかった統計情報のecho~はAIに質問しながら作り上げました。
